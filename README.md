# DEAD-MAN'S DIGITAL KEY 🔐
### Automated Cyber Heritage & Emergency Digital Recovery

> **A zero-trust digital inheritance and emergency account-recovery prototype designed to protect your most critical credentials, documents, and memories when you can no longer access them.**

---

## 🌟 Overview

People store years of valuable digital information across devices and online accounts — family photos, important documents, credentials, financial records, project files, recovery information, and other digital assets.

If they suddenly lose access to their primary device/account or become unavailable, their trusted family members may struggle to recover important information.

**Dead-Man's Digital Key** provides a secure, decentralized multi-signature recovery architecture where a user can configure an **Inactivity Heartbeat**, nominate **Trusted Contacts**, and define a multi-signature **2-of-3 consensus threshold** before encrypted emergency recovery packages can ever be released.

---

## 🚀 Key Features

- **Encrypted Digital Vault**: Simulated AES-256 encrypted storage for Photos, Documents, Credentials, Recovery Information, Important Files, and Digital Assets.
- **Inactivity Heartbeat Control**: Live ECG waveform monitor with configurable intervals (7, 14, 30, 60, 90 days), proof-of-life check-ins, and missed heartbeat emergency simulation.
- **2-of-3 Multi-Signature Trust Network**: Decentralized social recovery protocol requiring cryptographic consensus among nominated keyholders.
- **Emergency Release Center**: Real-time event tracking with step-by-step state machine from inactivity detection through multi-party authorization.
- **Emergency "What If?" Simulator**: Predefined scenario testing for lost devices, lockouts, suspicious activity, and unavailable keyholders.
- **Security Command Center & Audit Trail**: Category-filtered immutable audit logs, real-time threat detection, and legacy protection health breakdown.
- **Interactive Alert Workflow Builder**: Customizable alert timers, multi-channel notification rules, and quorum thresholds.
- **Recovery Drill Wizard**: Non-destructive 7-step drill verifying emergency readiness.
- **Digital Legacy Plan Builder**: Comprehensive 7-step wizard to create, review, and activate digital inheritance policies.

## 💻 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
